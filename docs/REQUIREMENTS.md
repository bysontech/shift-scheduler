# REQUIREMENTS.md

## 目的（1文）
医療従事者の管理職が、複雑な制約（希望休・業務適性・当直・相性など）を考慮しながら、勤務表を効率的に作成・調整できるWebアプリを提供する。

## Must

### 認証・データ保存
- メールアドレス＋パスワードでログイン
- アカウント作成
- アカウント作成不要のゲストログインも可能
- 設定・勤務表データの保存
- 勤務表履歴の保持

### 職員管理
- 職員の登録・編集・削除
- 業務ごとの担当可否設定
- 当直・オンコール上限設定
- グループ設定
- 相性NG設定

### 業務・シフト設定
- 月単位の勤務表作成
- 業務種類定義（通常・当直・オンコール・休み等）
- 必要人数設定

### 希望休管理
- CSV / Excel インポート
- 手動編集
- 原則アサイン不可

### 制約ルール
- 担当不可業務NG
- 独り立ち前単独NG
- 当直翌日は明け休み
- 上限回数遵守
- 希望休遵守
- 相性NG回避
- 必要人数充足

### 勤務表生成
- 制約ベース自動生成
- 手動編集可能
- 違反検知

### 作成不可時の原因表示
- 人数不足
- 対応可能者不足
- 上限制約
- 相性制約

### AI説明機能
- 原因の自然言語化
- 偏り指摘
- 改善ヒント

### 出力
- CSV / Excel 出力

## Should
- 偏り可視化
- 履歴考慮
- スコアリング
- AI改善提案

## Could
- 複数案生成
- モード切替
- UI改善
- 通知

## やらないこと
- 就業規則完全対応
- 本人申請
- 勤怠・給与
- 外部連携
- 労務判定

## 成功条件
- ログイン可能
- 設定可能
- 勤務表生成可能
- 原因表示可能
- 手動修正可能
- 出力可能
